# Chemyth 計画書

大学受験化学（共通テスト〜京大二次）を、工場自動化パズル（Shapez 系ジャンル）として学ぶブラウザゲーム。

## 0. 前提と目的

- **唯一の評価指標は「京大化学の過去問の得点」**。ゲームが面白いかどうかは二の次。
- 京大化学は大問4題、理科2科目で180分。理論・無機が2題、有機が2題（うち1題は天然高分子＝糖・アミノ酸/タンパク質が高頻度）。他大学より有機の比重が大きい（出典は末尾）。
- 共通テスト化学は新課程（2025年度〜）で、グラフ・資料の読み取りと考察問題の比率が上がっている。反応エンタルピー表記に移行済み。
- したがって優先順位は **有機（構造決定・反応経路）＞ 天然高分子 ＞ 理論計算 ＞ 無機知識**。開発順は実装しやすさも加味して §5 で決める。

### 京大の解答形式とゲームの相性

- 京大化学は長いリード文を読み、空欄（語句・化学式・反応式・数値・構造式）を埋める形式が中心。字数制限つきの論述や計算過程の記述は年に数問あるが主役ではない（2025年度第2問に60字論述と計算過程の指定あり）。
- つまり得点源は「文脈から**次に来る物質・反応・数値を即座に出す力**」。これは「いま手元にある物質から、納品指定された物質へ至る経路を自分で埋める」というゲームの操作と同型で、相性が良い。
- ゲームで足りないのは、初見の長文を制限時間内に読み切る訓練と、少数の論述。ここは過去問で補う。
- 「完璧に」の定義は「教科書の全単元（＋京大頻出の発展事項）がゲーム内の納品課題として存在する」こと。

## 1. コアデザイン：現実の資源地図から、指定物質を納品する

**ひとつの連続した世界**を探索し、各地の資源から工場を組んで、ハブが指定する物質を順に納品していく。モードは分けない。納品課題の列が教科書の単元順（＝カリキュラム）になっており、進めるうちに身につく。

### 産出の形の原則：天然にある姿のまま出す

入試は「天然に何の形で存在するか」と「そこからどう取り出すか」をセットで問う。したがって資源地は**天然での存在形態のまま**産出させ、元素の単体を直接は出さない。単体で出すのは、実際に単体で存在するものだけ。

| 天然での姿 | 例 | ゲームでの扱い | 入試で問われること |
|---|---|---|---|
| 単体の混合物 | 空気（N₂, O₂, Ar） | 「空気」を産出 → 分留 | N₂・O₂ の製法は液体空気の分留 |
| 水溶液などの混合物 | 海水、原油 | 「海水」「原油」を産出 → 蒸留・分留 | 分離法の名称と使い分け |
| 単体で産出 | 金、白金、硫黄、炭素（黒鉛・ダイヤモンド） | 単体のまま産出 | イオン化傾向が小さい金属は単体で存在する |
| 酸化物の鉱石 | 赤鉄鉱 Fe₂O₃、ボーキサイト Al₂O₃·nH₂O | 鉱石名つきの化合物を産出 → 還元 | 鉱石の主成分、還元法（炭素還元か溶融塩電解か） |
| 硫化物の鉱石 | 黄銅鉱 CuFeS₂、閃亜鉛鉱 ZnS、黄鉄鉱 FeS₂ | 同上 → 焙焼してから還元 | SO₂ の発生、粗銅と電解精錬 |
| 塩・炭酸塩 | 岩塩 NaCl、石灰石 CaCO₃、リン鉱石 Ca₃(PO₄)₂、蛍石 CaF₂ | 化合物を産出 | 熱分解、アンモニアソーダ法、肥料 |

金属は「イオン化傾向が大きいほど化合物から取り出しにくい」という一本の軸で製錬法が決まる（Al までは溶融塩電解、Zn〜Cu は炭素などで還元、Au・Pt は単体で産出）。地図上の資源地と必要な装置の重さが、そのままこの軸の体感になるように配置する。

各資源地はタップすると「採れるもの・産出の形・入試での問われ方」が出る。試作では海を「水」ではなく「海水（混合物）」に改め、蒸留で水と NaCl に分ける工程を入れた。

※ この表は教科書の標準的な内容に基づく。検索では入試での問われ方を直接裏づける資料を得られなかったので、鉱石名と主成分は実装時に教科書・図録と照合する。

### 建物＝化学操作

| 建物 | 意味 |
|---|---|
| 反応器 | 試薬・触媒・温度・圧力を**自分で指定**する。合っていれば動く |
| 電解槽 | 電極材料と電解液を指定。陽極・陰極の生成物が別の出口から出る。電流×時間で生成量が決まる（ファラデーの法則） |
| 電池 | 負極・正極・電解質を組むと電力が出る。**電力は電解槽と工場の動力になる**ので、電池と電気分解が一本の線でつながる |
| 分離機 | 蒸留、ろ過、抽出、再結晶、気体の乾燥・捕集（乾燥剤と捕集法の選択を誤ると失われる） |
| 分析器 | 検出反応（銀鏡、ヨードホルム、FeCl₃、炎色、沈殿）で流れを分岐 |
| 連結機・切断機 | 重合と加水分解（酵素） |

- 副生成物も実体として出てくる。処理しないと詰まるので、反応式全体を把握していないと進めない。
- ベルトの流量比＝物質量比。足りなければ余り、余れば詰まる。

### 納品課題の種類

1. **物質の納品**：「硝酸を納品せよ」→ 大気から N₂、水性ガスまたは電解で H₂、ハーバー・ボッシュ法、オストワルト法、と経路を自分で埋める。
2. **条件つき納品**（理論計算）：「pH 4.7 の緩衝液」「0.10 mol の銅を析出」「収率 x% 以上」。混合比・電流・温度圧力を**自分で計算して数値入力**する。選択肢は出さない。
3. **未知物の仕分け納品**（京大大問3）：農地や油田から出る異性体混合物を、分析器で分岐させ構造ごとに正しい納品口へ。分子式 C₄H₁₀O → C₅H₁₀O₂ → 芳香族エステルと難化。無機版は陽イオンの系統分離。
4. **配列・構造の決定納品**（京大大問4）：ペプチドを酵素で切断し断片からアミノ酸配列を確定、多糖の結合位置決定、重合度・平均分子量の指定。
5. **リード文課題**（終盤）：京大形式を模したオリジナルの長文を読み、空欄に当たる物質・数値を実際に作って納品する。

### 学習科学の組み込み

根拠のある手法だけを入れる。

- **想起練習（テスト効果）**：再読より想起の方が数日〜1週間後の保持が高い（Roediger & Karpicke 2006）。建物の試薬・条件は一覧から選ばせず、**自由入力またはヒントなし選択**を基本にする。
- **分散学習**：Dunlosky et al. (2013) が高い有用性とした手法。クリア済みステージの要素を間隔を空けて「再検定」として再出題する（簡易 SRS）。失敗した要素は間隔を短縮。
- **交互練習**：単元クリア後は分野混合の「京大チャレンジ」面で混ぜる。
- **誤答ログ**：どの反応・どの計算で詰まったかを記録し、弱点一覧を出す。ゲーム側の最重要成果物はこの一覧。
- **自動化の罠への対策**：一度組めば放置できてしまう。学習上は無意味なので、ブループリントの丸コピーは再検定を通過した要素だけに許可する。

### 入れないもの

- ログインボーナス、連続日数、放置報酬など、プレイ時間を引き延ばす仕組み全般。睡眠と他科目の時間を削るものは目的に反する。
- 1セッションは25分上限のタイマーを既定でオン。夜間は開始時に警告。

## 2. 内容の正確性の担保

間違った化学を覚えるゲームは有害なので、仕組みで守る。

- 物質・反応・ステージはすべて**データ（TypeScript の型付き定義）**として持ち、エンジンと分離。
- 全反応に対し **原子数収支・電荷収支の自動テスト**を CI で回す。
- 各反応データに出典欄（教科書・図録の該当単元）を必須にする。表記は新課程準拠（エンタルピー変化 ΔH、物質量の定義、単位）。
- 範囲は高校化学基礎＋化学の学習指導要領の単元一覧を「カバレッジ表」にし、各単元がどのステージで想起対象になるかを対応づける。空欄が残っている間は「完成」と呼ばない。
- 過去問の文章・図は著作物なので転載しない。**頻出テーマを踏まえたオリジナル問題**として作る。

## 3. 技術構成

- **TypeScript + Vite + Canvas 2D**、依存は最小。静的サイトとして GitHub Pages に配置、PWA 化してオフライン動作。
- シミュレーションは固定ティックの決定的ループ（描画と分離）。グリッド、ベルト、建物、アイテムの最小 ECS。
- セーブは localStorage / IndexedDB。サーバーは当面不要（端末間同期が必要になった時点で検討）。
- Shapez（shapez.io）は GPL-3 で公開されているが、**コード・アセットは流用せず独自実装**する。同ジャンルの仕組みを使うだけで、見た目・図形・ステージは別物。
- **対象はタブレット**。操作はすべてタッチ前提：1本指でなぞる・タップ、2本指で拡大縮小、押す場所は 44px 以上、道具バーは画面下。化学式の入力はソフトキーボード（全角・下付きは自動で吸収）。PC のマウスでも同じ操作で動く。

```
src/
  engine/     グリッド・ティック・ベルト・描画
  chem/       物質モデル、反応判定、収支チェック、定量計算
  content/    substances/ reactions/ stages/（データのみ）
  learn/      誤答ログ、再検定スケジューラ、カバレッジ表
  ui/
tests/        収支テスト、ステージ可解性テスト
```

## 4. 物質モデルの方針

- 無機・理論：組成式＋電荷＋状態＋量。反応はデータ表の照合で十分。
- 有機：**分子グラフ**（原子＋結合）で保持し、官能基はグラフから検出する。反応は「官能基パターン → 変換規則」で定義。これにより異性体の列挙と仕分け課題の自動採点ができる。立体（鏡像・シス-トランス）は不斉炭素と二重結合のフラグで扱う。
- 表示は構造式の自動レイアウト。ここは技術的に最も重いので M2 の最初に試作してリスクを潰す。

## 5. マイルストーン

各段階の完了条件は「動く＋その範囲の収支テストが通る＋実際に遊んで誤答ログが取れる」。

| 段階 | 内容 | 完了条件 |
|---|---|---|
| **M0** 縦切り試作 | グリッド、ベルト、資源地（大気・海）、反応器、ハブ、セーブ | 大気と水からアンモニアを納品できる |
| **M1** 無機工業と電気 | 資源地図の全体、工業的製法、電解槽、電池と電力網、分離機、気体の製法 | 硝酸・硫酸・炭酸ナトリウム・鉄・アルミニウム・純銅を納品できる |
| **M2** 有機 | 油田からの分子グラフ、脂肪族→芳香族の合成経路、**異性体の仕分け納品** | C₄〜C₈ の仕分け課題が自動生成・自動採点できる |
| **M3** 高分子 | 農地からの糖・アミノ酸/ペプチド・油脂、合成高分子、切断・連結 | 配列決定課題と重合度計算課題がある |
| **M4** 理論定量 | 平衡、酸塩基・緩衝液、溶解度積、気体、熱化学、速度、結晶を条件つき納品に | 数値入力の課題が各単元にある |
| **M5** 学習機能 | 再検定スケジューラ、弱点一覧、カバレッジ表示、リード文課題 | 弱点一覧から該当課題へ直行できる |

M2 が京大対策として最も価値が高い。M1 を先にするのは、エンジンを固めるのに無機工業が一番単純だから。M1 は薄く作って早く M2 に入る。

#### 京大の出題形式と、それに合わせた演習

予備校の分析と大学の公表資料で確かめた、2022〜2026 年度の京大・化学（理系）の形：

- 大問 4 題。I・II が理論（I は無機・結晶・電気化学と絡める）、III が有機の構造決定、IV が天然高分子（糖・アミノ酸・ペプチド）。5 年間この配置は変わっていない。理科 2 科目で 180 分。
- どの大問も問題文が長く、空欄の答えが次の設問に連動する。論述と計算過程の記述は年によって有無が変わる（2022〜24 と 2026 は無し、2025 は有り）。
- 理論は化学平衡（気体の平衡、蒸気圧、電離平衡、溶解度積、分配・吸着）、結晶、電気化学。物質収支を文字式で表す設問が多い。
- III は構造式を描いて答える。IV はペプチドの配列決定、糖の構造が繰り返し出る。核酸はこの 5 年出ていない。合成高分子は 2025 年の III に一度だけ。

出典：河合塾 入試問題分析（2022〜2025）、駿台・代々木ゼミナール 解答速報の分析（2026）、京都大学 出題意図・募集要項（令和 8 年度）。東進の講評は読めなかった。

これに合わせて、工場の外に 3 種類の演習を置いた（メニューから開く）。どれも乱数で作るので、同じ問題を覚えて答えることはできない。

| 演習 | 京大の大問 | しくみ |
|---|---|---|
| 連鎖計算 | I・II | 1 つの設定から 4〜6 問を順に解く。前の答えを次に使う。数値は開くたびに変わる。答えは式から計算し、テストで別の経路の検算と突き合わせる |
| 構造決定（数え上げ・特定）※組み込み中。エンジンのテストが通りしだい入れる | III | 分子式から、鎖式・一置換・二置換ベンゼンの構造異性体をその場で全部作る。性質（級数、酸化、ヨードホルム、銀鏡、脱水、加水分解、オゾン分解、不斉炭素、シス-トランス）は構造から計算する。「特定」は、手がかりを全部満たす異性体が 1 つだけであることを総当たりで確かめてから出す |
| ペプチドの配列決定 | IV | 3〜5 個のアミノ酸の配列を乱数で決め、末端、酵素による切断で生じる断片の呈色反応、部分加水分解のジペプチドを手がかりにする。こちらも答えが 1 つに決まることを総当たりで確かめる |

それでも足りないところ：

- 構造式を「描く」練習にはなっていない。構造決定の答えは、示性式の選択肢から選ぶ。
- 物質収支を文字式で表す設問、論述、グラフの読み取り・作図、実験装置の図は扱っていない。
- 構造決定は、環（シクロアルカン、ラクトンなど）、三置換以上のベンゼン、窒素を含む化合物（アミド、アミノ酸の異性体）を作れない。京大では 2023〜2025 年にこれらが出ている。
- 糖の構造（グリコシド結合の位置、メチル化分析）は扱っていない。
- 連鎖計算の文章は短い。京大の長いリード文を読む負荷は再現していない。過去問演習の代わりにはならない。
- 項目の「points」は自分で書き出したもので、教科書の索引との全件照合はしていない。

#### 装置の大きさと出入口

- 蒸留塔・反応器・電解槽・電池は 2×2 マス。出口は 6 か所（正面に 2、右手に 2、左手に 2）で、奥の面の 2 マスが入口の目安。原料はどの面からでも入る。
- 出口には、そこから出る物質の絵柄を描く。設定シートの図で、出口をタップして場所を入れ替えられる。
- 電解槽は左半分が陰極、右半分が陽極。生成物の欄は極ごとに分かれ、1 つの極に 3 つまで書ける。陰極側のものは左手、陽極側のものは右手から出る。以前は「陰極・陽極・ほか」の 3 欄しかなく、硫酸銅(II)水溶液の陽極（O₂ と H⁺）や、アルミナの溶融塩電解の陽極（CO と CO₂）を書けなかった。
- 1 マスだった頃に置いた装置は、古いセーブの中ではそのまま 3 つの出口で動く。新しく置くものはすべて 2×2。

#### 別解の受け付け

同じ原料から別の生成物ができる反応、同じ目的に別の試薬を使う反応を足した。以前は片方しか正解にならなかった。

- 炭素と酸素：CO₂（完全燃焼）と CO。二酸化炭素とコークス。酸化亜鉛の炭素還元の CO₂ の式。
- アルミナの溶融塩電解：陽極が CO₂ だけ、CO だけ、両方（係数は原子の数が合えばよい）。
- 水素・硫化水素の製法での塩酸、二酸化硫黄の製法での亜硫酸ナトリウム、サリチル酸とフェノールの遊離での塩酸。
- ニトロベンゼンの還元：水素と触媒のほかに、スズと塩酸（アニリン塩酸塩になる）と、その後のアニリンの遊離。
- 水溶液の電気分解：CuSO₄、AgNO₃、CuCl₂、KI。
- 酸化還元の反応式：KMnO₄ と H₂O₂、KMnO₄ とシュウ酸、SO₂ と H₂S、H₂O₂ と KI、ヨウ素とチオ硫酸ナトリウム。生成物が 4 つあるので、出口が 3 つの頃は入れられなかった。

#### 海水

以前は地図の西がどこまでも海だった。これをやめ、海はほかの資源地と同じ「点在する場所」にした。最初の区画には、西に海が 1 つと、入り江が 4 か所（納品所の東、南西、東の端、北）ある。西へ進んでも陸地が続き、資源地が現れる。遠くの区画にも、ほかの資源地の 3 倍の割合で現れる。

- 納品所は、達成数が 3・12・30 に達すると 2×2 → 4×4 → 6×6 → 8×8 に広がる。受け取れる口が増えるかわりに、1 つの指令で求められる数が 1.5 倍・2 倍・3 倍になる（仕分けの指令は増やさない）。広がった場所に重なった設備は撤去される。
- 「全体」は、建てたもの全体が収まる視野に切り替える。

#### ランキングと公開

- GitHub Pages：`.github/workflows/pages.yml` がテスト・ビルド・公開まで行う。リポジトリの Settings → Pages で Source を「GitHub Actions」にする必要がある。
- ランキング：達成数 → 研究点 → 時間の順。Supabase のプロジェクト「chemyth」につないである（`src/config.ts`、表の定義は `supabase/migrations/0001_ranking.sql`）。表には直接さわらせず、登録用と取得用の関数だけを公開する。接続できないときは、この端末のノート同士の順位だけを出す。
- 成績は自己申告なので、不正は完全には防げない。

#### 運転条件の計算

塩化銀の沈殿、窒素のボンベ充填、ヨウ化水素の分解は、反応の設定が合ったあとに、その装置の条件（沈殿が始まる濃度、ボンベの圧力、速度の変化）を計算して入力しないと動かない。

#### 仕分けの課題の仕組み

- 「試薬棚」で試料の組を選ぶと、絵柄では区別できない数種類が順に流れてくる。
- 「分析器」は検査を 1 つ行い、陽性を正面、陰性を右手へ分ける。直列につなげば条件を重ねられる。
- 目的の物質だけを納品する。同じ試料の別の物質を納めると 2 個減点。
- 各検査で「わかること」は折りたたんであり、まず自分で思い出す前提。
- テストで、仕分けの指令すべてについて、目的の物質が検査の組み合わせで他と区別できることを確認している。

#### 可逆反応と緩衝液

- ハーバー・ボッシュ法、接触法、メタノール合成、水蒸気改質、石灰石の熱分解は、触媒に加えて「平衡を生成物側へ動かす温度と圧力」も答えないと動かない。
- 緩衝液は、酢酸と酢酸ナトリウムの混合比を係数で指定する。Ka から比を計算する。

#### 専用パイプについての判断

液体・気体を専用のパイプで運ぶ案は、**別の道具にはしなかった**。理由：

1. 工業プロセスでは反応条件下の状態と常温の状態が食い違う物質が多く（SO₃、アセトアルデヒド、水溶液として扱う NaOH など）、「正しい管」を一意に決められない。誤った暗記を誘う。
2. 道具の持ち替えが増える。タブレットでの手数は、以前に指摘された弱点そのもの。
3. 入試で状態が問われるのは、ハロゲンの単体や捕集法など限られた場面で、そこは第 8 章と復習の知識問題で直接扱える。

代わりに、**線の見た目が、流れている物質の常温での状態で自動的に変わる**ようにした（固体＝幅広のコンベヤ、液体＝管、気体＝細い管）。操作は増えず、状態は常に目に入る。物質の台の形（丸・しずく・角丸）と対応している。

#### 便利機能

- ベルトを引いて別のベルトをまっすぐ横切ると、交点が自動で立体交差になる。直角に乗って止めれば合流。立体交差は最初から使える。
- 早送り（×1 → ×2 → ×4 → 停止）。
- 複製：設定済みの装置を選んで「複」を押すと、同じ設定で続けて置ける。
- 詰まりの表示：出口がふさがった装置には「!」が付き、設定画面に「何が足りないか／どの出口が詰まっているか」が出る。
- 試薬棚：実験室の試薬 20 種を取り出せる（そのまま納品しても指令には数えない）。

#### 弱いところ

- 難易度と所要時間は、人が通しで遊んで調整していない。指令ごとの所要時間は記録しているので（記録画面）、遊んだあとに数字で見直せる。
- 工場の中の仕分けの指令は、用意した 23 組の試料から区別できる物質を拾う方式。新しい分子を作り出すのは、工場の外の「構造決定」の演習だけ。
- 解説文・検査の表・問題の答えは、一部を検索で裏取りしただけ（乾燥剤、両性と錯イオン、ヨードホルム反応、鉛蓄電池）。教科書との全件照合はしていない。

#### 仕組みの追加（これまで）

- **立体交差の直後の曲がり**：立体交差を抜けた先のベルトが曲がっていると流れが途切れる不具合を直した（立体交差の先は、入ってきた向きのまま受け取る）。

- **元素ごとの固有の形**：物質の絵柄は元素の形の組み合わせ。色は炎色反応や単体・イオンの色に合わせた。
- **大気はどこでも採れる**。
- **強化**：研究点と計算問題で、採取・ベルト・装置が 5 段階まで速くなる。
- **装置**：電池、分配器、立体交差、搬出口、試薬棚、分析器、捕集器。
- **あふれ**：装置に入れすぎた原料は捨てられ、1 本のベルトに混ぜても詰まらない。
- **図鑑**、**タイトル画面とセーブ 3 枠**（端末ごと。文字列で書き出し・読み込み）、**音**。

### 操作と見た目の方針（タブレット）

- システムキーボードを出さない。化学式は専用キー（元素を多めに並べ、答えの手がかりにしない）、係数は −／＋、条件は選択肢のタップ。
- 道具の持ち替えを減らす。置いたものをタップすると、その場に「設定・回す・消す」が出る。装置やベルトから指を引くとベルトが伸びる。
- 置く向きは、流れ込みがあればその向き、なければ納品所の方角に自動で決める。
- 最初は指で押せる大きさで始め、「全体」で地図全体へ切り替える。画面外の資源地は縁の道しるべで示す。指を離すと地図は少し滑る。
- 見た目は有機的に：地形はマス目ではなくにじんだ塊、資源地は不定形、ベルトは角で曲がる一続きの管、装置と UI は丸い形。

## 6. リスク

1. **開発が勉強時間を食う**。最大のリスク。実装は任せて、本人の作業は「遊んで誤答ログを残す＝勉強」に限定する。仕様に凝り始めたら危険信号。
2. **受験までの残り期間**。高3で今（11月）から始めるなら、このゲームは間に合わず有害。過去問と共テ演習に全振りすべき。高1・高2なら M2 までを早期に作れば元が取れる。→ 学年で計画の規模を変える。
3. **有機の構造式表示と反応規則**が重い。M2 冒頭で試作し、無理なら扱う化合物を教科書掲載の範囲に限定した表引き方式へ落とす。
4. **内容の誤り**。§2 の自動テストと出典必須で抑えるが、最終確認は教科書と照合する。
