# Chemyth 計画書

大学受験化学（共通テスト〜京大二次）を、工場自動化パズル（Shapez 系ジャンル）として学ぶブラウザゲーム。

## 0. 前提と目的

- **唯一の評価指標は「京大化学の過去問の得点」**。ゲームが面白いかどうかは二の次。
- 京大化学は大問4題、理科2科目で180分。理論・無機が2題、有機が2題（うち1題は天然高分子＝糖・アミノ酸/タンパク質が高頻度）。他大学より有機の比重が大きい（出典は末尾）。
- 共通テスト化学は新課程（2025年度〜）で、グラフ・資料の読み取りと考察問題の比率が上がっている。反応エンタルピー表記に移行済み。
- したがって優先順位は **有機（構造決定・反応経路）＞ 天然高分子 ＞ 理論計算 ＞ 無機知識**。開発順は実装しやすさも加味して §5 で決める。

### このゲームでできないこと（正直に）

- 京大の答案は手書きの計算過程と論述。ゲームは「知識のネットワーク化」「反応経路の即時想起」「量的関係の感覚」までは作れるが、**答案作成力は過去問を紙で解く以外に身につかない**。
- よって「完璧に」の定義は「教科書の全単元がゲーム内で想起練習の対象になっている」こと。過去問演習の代替ではなく、その前段を高速化する道具と位置づける。

## 1. コアデザイン：操作そのものが化学であること

クイズを工場の皮で包むだけなら問題集の劣化版になる。**ベルトを流れるもの＝物質、建物＝化学操作、ハブの納品要求＝問題**とし、ラインを組む行為が解法そのものになるようにする。

| ゲーム要素 | 化学での意味 |
|---|---|
| アイテム | 物質（分子・イオン・混合物）。量（mol）、状態、濃度を持つ |
| 採掘機 | 原料（空気、海水、石灰石、石油、鉱石、ベンゼン等） |
| 加工建物 | 反応・操作（酸化、還元、付加、脱水、エステル化、加水分解、中和、電気分解、蒸留、ろ過、重合） |
| 建物の設定 | 試薬・触媒・温度・圧力の選択（ここが知識の想起点） |
| ベルトの流量比 | 物質量比（化学量論） |
| ハブ | 目的物の純度・量・条件を指定して要求する |
| 副生成物 | 処理しないとラインが詰まる（反応式を全部書けないと進めない） |

### 4つのモード

1. **合成モード**（順方向）：原料から目的物を作る。
   無機の工業的製法（ハーバー・ボッシュ法、オストワルト法、接触法、アンモニアソーダ法、製錬、電解精錬）は元々が工場なので最も自然に載る。有機は反応経路図そのもの（エチレン→エタノール→アセトアルデヒド→酢酸→酢酸エチル、ベンゼン→…→アゾ染料 等）。
2. **同定モード**（逆方向）＝京大大問3対策の中核：
   正体不明の異性体群が流れてくる。検出反応（ヨードホルム反応、銀鏡反応、フェーリング、臭素水、Na、NaHCO₃、FeCl₃、オゾン分解、元素分析、不斉炭素の有無）の建物で分岐させ、構造ごとに正しい出口へ仕分ける。分子式 C₄H₁₀O → C₅H₁₀O₂ → 芳香族エステルと難化。
   無機版は陽イオンの系統分離（HCl → H₂S → NH₃ → …）と気体の発生・捕集・乾燥剤選択。
3. **切断・連結モード**（高分子）＝京大大問4対策：
   重合＝連結機、加水分解・酵素＝切断機。ペプチドを酵素で切って断片からアミノ酸配列を決定する、多糖をメチル化→加水分解して結合位置を決める、等を仕分けパズルにする。重合度・平均分子量の計算を納品条件にする。
4. **定量モード**（理論）：
   納品条件が数値。「pH 4.7 の緩衝液」「平衡時の NH₃ 収率 x% 以上」「銅を 0.10 mol 析出」など。流量・濃度・温度・圧力・電流を**プレイヤーが自分で計算して数値入力**する（選択肢なし）。平衡、酸塩基、溶解度積、電池・電気分解、気体、蒸気圧、希薄溶液、反応速度、熱化学（エンタルピー）、結晶格子。

### 学習科学の組み込み

根拠のある手法だけを入れる。

- **想起練習（テスト効果）**：再読より想起の方が数日〜1週間後の保持が高い（Roediger & Karpicke 2006）。建物の試薬・条件は一覧から選ばせず、**自由入力またはヒントなし選択**を基本にする。
- **分散学習**：Dunlosky et al. (2013) が高い有用性とした手法。クリア済みステージの要素を間隔を空けて「再検定」として再出題する（簡易 SRS）。失敗した要素は間隔を短縮。
- **交互練習**：単元クリア後は分野混合の「京大チャレンジ」面で混ぜる。
- **誤答ログ**：どの反応・どの計算で詰まったかを記録し、弱点一覧を出す。ゲーム側の最重要成果物はこの一覧。
- **自動化の罠への対策**：Shapez 系は一度組めば放置できる。学習上は無意味なので、ブループリントの丸コピーは再検定を通過した要素だけに許可する。

### 入れないもの

- ログインボーナス、連続日数、放置報酬など、プレイ時間を引き延ばす仕組み全般。睡眠と他科目の時間を削るものは目的に反する。
- 1セッションは25分上限のタイマーを既定でオン。夜間は開始時に警告。

## 2. 内容の正確性の担保

間違った化学を覚えるゲームは有害なので、仕組みで守る。

- 物質・反応・ステージはすべて**データ（TypeScript の型付き定義）**として持ち、エンジンと分離。
- 全反応に対し **原子数収支・電荷収支の自動テスト**を CI で回す。
- 各反応データに出典欄（教科書・図録の該当単元）を必須にする。表記は新課程準拠（エンタルピー変化 ΔH、物質量の定義、単位）。
- 範囲は高校化学基礎＋化学の学習指導要領の単元一覧を「カバレッジ表」にし、各単元がどのステージで想起対象になるかを対応づける。空欄が残っている間は「完成」と呼ばない。
- 過去問の文章・図は著作物なので転載しない。**頻出テーマを踏まえたオリジナル問題**として作る。

## 3. 技術構成

- **TypeScript + Vite + Canvas 2D**、依存は最小。静的サイトとして GitHub Pages に配置、PWA 化してオフライン動作。
- シミュレーションは固定ティックの決定的ループ（描画と分離）。グリッド、ベルト、建物、アイテムの最小 ECS。
- セーブは localStorage / IndexedDB。サーバーは当面不要（端末間同期が必要になった時点で検討）。
- Shapez（shapez.io）は GPL-3 で公開されているが、**コード・アセットは流用せず独自実装**する。同ジャンルの仕組みを使うだけで、見た目・図形・ステージは別物。
- 対象は PC ブラウザ優先、タブレットのタッチ操作まで対応。スマホは同定モードなど小盤面のみ。

```
src/
  engine/     グリッド・ティック・ベルト・描画
  chem/       物質モデル、反応判定、収支チェック、定量計算
  content/    substances/ reactions/ stages/（データのみ）
  learn/      誤答ログ、再検定スケジューラ、カバレッジ表
  ui/
tests/        収支テスト、ステージ可解性テスト
```

## 4. 物質モデルの方針

- 無機・理論：組成式＋電荷＋状態＋量。反応はデータ表の照合で十分。
- 有機：**分子グラフ**（原子＋結合）で保持し、官能基はグラフから検出する。反応は「官能基パターン → 変換規則」で定義。これにより異性体の列挙と同定モードの自動採点ができる。立体（鏡像・シス-トランス）は不斉炭素と二重結合のフラグで扱う。
- 表示は構造式の自動レイアウト。ここは技術的に最も重いので M2 の最初に試作してリスクを潰す。

## 5. マイルストーン

各段階の完了条件は「動く＋その範囲の収支テストが通る＋実際に遊んで誤答ログが取れる」。

| 段階 | 内容 | 完了条件 |
|---|---|---|
| **M0** 縦切り試作 | グリッド、ベルト、採掘機、反応器1種、ハブ、セーブ | アンモニア合成の1面がクリアできる |
| **M1** 無機工業 | 工業的製法6種、気体の製法と捕集、陽イオン系統分離（同定モードの原型） | 無機の主要単元がカバレッジ表で埋まる |
| **M2** 有機 | 分子グラフ、脂肪族→芳香族の合成経路、**構造決定の同定モード** | C₄〜C₈ の異性体仕分け面が自動生成・自動採点できる |
| **M3** 高分子 | 糖・アミノ酸/ペプチド・合成高分子、切断・連結モード | 配列決定面と重合度計算面がある |
| **M4** 理論定量 | 平衡、酸塩基・緩衝液、溶解度積、電気化学、気体、熱化学、速度、結晶 | 数値入力納品の面が各単元にある |
| **M5** 学習機能 | 再検定スケジューラ、弱点一覧、カバレッジ表示、分野混合チャレンジ | 弱点一覧から該当面へ直行できる |

M2 が京大対策として最も価値が高い。M1 を先にするのは、エンジンを固めるのに無機工業が一番単純だから。M1 は薄く作って早く M2 に入る。

## 6. リスク

1. **開発が勉強時間を食う**。最大のリスク。実装は任せて、本人の作業は「遊んで誤答ログを残す＝勉強」に限定する。仕様に凝り始めたら危険信号。
2. **受験までの残り期間**。高3で今（11月）から始めるなら、このゲームは間に合わず有害。過去問と共テ演習に全振りすべき。高1・高2なら M2 までを早期に作れば元が取れる。→ 学年で計画の規模を変える。
3. **有機の構造式表示と反応規則**が重い。M2 冒頭で試作し、無理なら扱う化合物を教科書掲載の範囲に限定した表引き方式へ落とす。
4. **内容の誤り**。§2 の自動テストと出典必須で抑えるが、最終確認は教科書と照合する。

## 7. 着手前に決めること

- 学年（受験年度）→ 規模と優先順位が変わる。
- 主に使う端末（PC / タブレット）。
- 使っている教科書・図録（表記と出典をそれに合わせる）。
