# Chemyth 計画書

大学受験化学（共通テスト〜京大二次）を、工場自動化パズル（Shapez 系ジャンル）として学ぶブラウザゲーム。

## 0. 前提と目的

- **唯一の評価指標は「京大化学の過去問の得点」**。ゲームが面白いかどうかは二の次。
- 京大化学は大問4題、理科2科目で180分。理論・無機が2題、有機が2題（うち1題は天然高分子＝糖・アミノ酸/タンパク質が高頻度）。他大学より有機の比重が大きい（出典は末尾）。
- 共通テスト化学は新課程（2025年度〜）で、グラフ・資料の読み取りと考察問題の比率が上がっている。反応エンタルピー表記に移行済み。
- したがって優先順位は **有機（構造決定・反応経路）＞ 天然高分子 ＞ 理論計算 ＞ 無機知識**。開発順は実装しやすさも加味して §5 で決める。

### 京大の解答形式とゲームの相性

- 京大化学は長いリード文を読み、空欄（語句・化学式・反応式・数値・構造式）を埋める形式が中心。字数制限つきの論述や計算過程の記述は年に数問あるが主役ではない（2025年度第2問に60字論述と計算過程の指定あり）。
- つまり得点源は「文脈から**次に来る物質・反応・数値を即座に出す力**」。これは「いま手元にある物質から、納品指定された物質へ至る経路を自分で埋める」というゲームの操作と同型で、相性が良い。
- ゲームで足りないのは、初見の長文を制限時間内に読み切る訓練と、少数の論述。ここは過去問で補う。
- 「完璧に」の定義は「教科書の全単元（＋京大頻出の発展事項）がゲーム内の納品課題として存在する」こと。

## 1. コアデザイン：現実の資源地図から、指定物質を納品する

**ひとつの連続した世界**を探索し、各地の資源から工場を組んで、ハブが指定する物質を順に納品していく。モードは分けない。納品課題の列が教科書の単元順（＝カリキュラム）になっており、進めるうちに身につく。

### 産出の形の原則：天然にある姿のまま出す

入試は「天然に何の形で存在するか」と「そこからどう取り出すか」をセットで問う。したがって資源地は**天然での存在形態のまま**産出させ、元素の単体を直接は出さない。単体で出すのは、実際に単体で存在するものだけ。

| 天然での姿 | 例 | ゲームでの扱い | 入試で問われること |
|---|---|---|---|
| 単体の混合物 | 空気（N₂, O₂, Ar） | 「空気」を産出 → 分留 | N₂・O₂ の製法は液体空気の分留 |
| 水溶液などの混合物 | 海水、原油 | 「海水」「原油」を産出 → 蒸留・分留 | 分離法の名称と使い分け |
| 単体で産出 | 金、白金、硫黄、炭素（黒鉛・ダイヤモンド） | 単体のまま産出 | イオン化傾向が小さい金属は単体で存在する |
| 酸化物の鉱石 | 赤鉄鉱 Fe₂O₃、ボーキサイト Al₂O₃·nH₂O | 鉱石名つきの化合物を産出 → 還元 | 鉱石の主成分、還元法（炭素還元か溶融塩電解か） |
| 硫化物の鉱石 | 黄銅鉱 CuFeS₂、閃亜鉛鉱 ZnS、黄鉄鉱 FeS₂ | 同上 → 焙焼してから還元 | SO₂ の発生、粗銅と電解精錬 |
| 塩・炭酸塩 | 岩塩 NaCl、石灰石 CaCO₃、リン鉱石 Ca₃(PO₄)₂、蛍石 CaF₂ | 化合物を産出 | 熱分解、アンモニアソーダ法、肥料 |

金属は「イオン化傾向が大きいほど化合物から取り出しにくい」という一本の軸で製錬法が決まる（Al までは溶融塩電解、Zn〜Cu は炭素などで還元、Au・Pt は単体で産出）。地図上の資源地と必要な装置の重さが、そのままこの軸の体感になるように配置する。

各資源地はタップすると「採れるもの・産出の形・入試での問われ方」が出る。試作では海を「水」ではなく「海水（混合物）」に改め、蒸留で水と NaCl に分ける工程を入れた。

※ この表は教科書の標準的な内容に基づく。検索では入試での問われ方を直接裏づける資料を得られなかったので、鉱石名と主成分は実装時に教科書・図録と照合する。

### 建物＝化学操作

| 建物 | 意味 |
|---|---|
| 反応器 | 試薬・触媒・温度・圧力を**自分で指定**する。合っていれば動く |
| 電解槽 | 電極材料と電解液を指定。陽極・陰極の生成物が別の出口から出る。電流×時間で生成量が決まる（ファラデーの法則） |
| 電池 | 負極・正極・電解質を組むと電力が出る。**電力は電解槽と工場の動力になる**ので、電池と電気分解が一本の線でつながる |
| 分離機 | 蒸留、ろ過、抽出、再結晶、気体の乾燥・捕集（乾燥剤と捕集法の選択を誤ると失われる） |
| 分析器 | 検出反応（銀鏡、ヨードホルム、FeCl₃、炎色、沈殿）で流れを分岐 |
| 連結機・切断機 | 重合と加水分解（酵素） |

- 副生成物も実体として出てくる。処理しないと詰まるので、反応式全体を把握していないと進めない。
- ベルトの流量比＝物質量比。足りなければ余り、余れば詰まる。

### 納品課題の種類

1. **物質の納品**：「硝酸を納品せよ」→ 大気から N₂、水性ガスまたは電解で H₂、ハーバー・ボッシュ法、オストワルト法、と経路を自分で埋める。
2. **条件つき納品**（理論計算）：「pH 4.7 の緩衝液」「0.10 mol の銅を析出」「収率 x% 以上」。混合比・電流・温度圧力を**自分で計算して数値入力**する。選択肢は出さない。
3. **未知物の仕分け納品**（京大大問3）：農地や油田から出る異性体混合物を、分析器で分岐させ構造ごとに正しい納品口へ。分子式 C₄H₁₀O → C₅H₁₀O₂ → 芳香族エステルと難化。無機版は陽イオンの系統分離。
4. **配列・構造の決定納品**（京大大問4）：ペプチドを酵素で切断し断片からアミノ酸配列を確定、多糖の結合位置決定、重合度・平均分子量の指定。
5. **リード文課題**（終盤）：京大形式を模したオリジナルの長文を読み、空欄に当たる物質・数値を実際に作って納品する。

### 学習科学の組み込み

根拠のある手法だけを入れる。

- **想起練習（テスト効果）**：再読より想起の方が数日〜1週間後の保持が高い（Roediger & Karpicke 2006）。建物の試薬・条件は一覧から選ばせず、**自由入力またはヒントなし選択**を基本にする。
- **分散学習**：Dunlosky et al. (2013) が高い有用性とした手法。クリア済みステージの要素を間隔を空けて「再検定」として再出題する（簡易 SRS）。失敗した要素は間隔を短縮。
- **交互練習**：単元クリア後は分野混合の「京大チャレンジ」面で混ぜる。
- **誤答ログ**：どの反応・どの計算で詰まったかを記録し、弱点一覧を出す。ゲーム側の最重要成果物はこの一覧。
- **自動化の罠への対策**：一度組めば放置できてしまう。学習上は無意味なので、ブループリントの丸コピーは再検定を通過した要素だけに許可する。

### 入れないもの

- ログインボーナス、連続日数、放置報酬など、プレイ時間を引き延ばす仕組み全般。睡眠と他科目の時間を削るものは目的に反する。
- 1セッションは25分上限のタイマーを既定でオン。夜間は開始時に警告。

## 2. 内容の正確性の担保

間違った化学を覚えるゲームは有害なので、仕組みで守る。

- 物質・反応・ステージはすべて**データ（TypeScript の型付き定義）**として持ち、エンジンと分離。
- 全反応に対し **原子数収支・電荷収支の自動テスト**を CI で回す。
- 各反応データに出典欄（教科書・図録の該当単元）を必須にする。表記は新課程準拠（エンタルピー変化 ΔH、物質量の定義、単位）。
- 範囲は高校化学基礎＋化学の学習指導要領の単元一覧を「カバレッジ表」にし、各単元がどのステージで想起対象になるかを対応づける。空欄が残っている間は「完成」と呼ばない。
- 過去問の文章・図は著作物なので転載しない。**頻出テーマを踏まえたオリジナル問題**として作る。

## 3. 技術構成

- **TypeScript + Vite + Canvas 2D**、依存は最小。静的サイトとして GitHub Pages に配置、PWA 化してオフライン動作。
- シミュレーションは固定ティックの決定的ループ（描画と分離）。グリッド、ベルト、建物、アイテムの最小 ECS。
- セーブは localStorage / IndexedDB。サーバーは当面不要（端末間同期が必要になった時点で検討）。
- Shapez（shapez.io）は GPL-3 で公開されているが、**コード・アセットは流用せず独自実装**する。同ジャンルの仕組みを使うだけで、見た目・図形・ステージは別物。
- **対象はタブレット**。操作はすべてタッチ前提：1本指でなぞる・タップ、2本指で拡大縮小、押す場所は 44px 以上、道具バーは画面下。化学式の入力はソフトキーボード（全角・下付きは自動で吸収）。PC のマウスでも同じ操作で動く。

```
src/
  engine/     グリッド・ティック・ベルト・描画
  chem/       物質モデル、反応判定、収支チェック、定量計算
  content/    substances/ reactions/ stages/（データのみ）
  learn/      誤答ログ、再検定スケジューラ、カバレッジ表
  ui/
tests/        収支テスト、ステージ可解性テスト
```

## 4. 物質モデルの方針

- 無機・理論：組成式＋電荷＋状態＋量。反応はデータ表の照合で十分。
- 有機：**分子グラフ**（原子＋結合）で保持し、官能基はグラフから検出する。反応は「官能基パターン → 変換規則」で定義。これにより異性体の列挙と仕分け課題の自動採点ができる。立体（鏡像・シス-トランス）は不斉炭素と二重結合のフラグで扱う。
- 表示は構造式の自動レイアウト。ここは技術的に最も重いので M2 の最初に試作してリスクを潰す。

## 5. マイルストーン

各段階の完了条件は「動く＋その範囲の収支テストが通る＋実際に遊んで誤答ログが取れる」。

| 段階 | 内容 | 完了条件 |
|---|---|---|
| **M0** 縦切り試作 | グリッド、ベルト、資源地（大気・海）、反応器、ハブ、セーブ | 大気と水からアンモニアを納品できる |
| **M1** 無機工業と電気 | 資源地図の全体、工業的製法、電解槽、電池と電力網、分離機、気体の製法 | 硝酸・硫酸・炭酸ナトリウム・鉄・アルミニウム・純銅を納品できる |
| **M2** 有機 | 油田からの分子グラフ、脂肪族→芳香族の合成経路、**異性体の仕分け納品** | C₄〜C₈ の仕分け課題が自動生成・自動採点できる |
| **M3** 高分子 | 農地からの糖・アミノ酸/ペプチド・油脂、合成高分子、切断・連結 | 配列決定課題と重合度計算課題がある |
| **M4** 理論定量 | 平衡、酸塩基・緩衝液、溶解度積、気体、熱化学、速度、結晶を条件つき納品に | 数値入力の課題が各単元にある |
| **M5** 学習機能 | 再検定スケジューラ、弱点一覧、カバレッジ表示、リード文課題 | 弱点一覧から該当課題へ直行できる |

M2 が京大対策として最も価値が高い。M1 を先にするのは、エンジンを固めるのに無機工業が一番単純だから。M1 は薄く作って早く M2 に入る。

#### 京大の出題形式と、それに合わせた演習

予備校の分析と大学の公表資料で確かめた、2022〜2026 年度の京大・化学（理系）の形：

- 大問 4 題。I・II が理論（I は無機・結晶・電気化学と絡める）、III が有機の構造決定、IV が天然高分子（糖・アミノ酸・ペプチド）。5 年間この配置は変わっていない。理科 2 科目で 180 分。
- どの大問も問題文が長く、空欄の答えが次の設問に連動する。論述と計算過程の記述は年によって有無が変わる（2022〜24 と 2026 は無し、2025 は有り）。
- 理論は化学平衡（気体の平衡、蒸気圧、電離平衡、溶解度積、分配・吸着）、結晶、電気化学。物質収支を文字式で表す設問が多い。
- III は構造式を描いて答える。IV はペプチドの配列決定、糖の構造が繰り返し出る。核酸はこの 5 年出ていない。合成高分子は 2025 年の III に一度だけ。

出典：河合塾 入試問題分析（2022〜2025）、駿台・代々木ゼミナール 解答速報の分析（2026）、京都大学 出題意図・募集要項（令和 8 年度）。東進の講評は読めなかった。

これに合わせて、工場の外に 3 種類の演習を置いた（メニューから開く）。どれも乱数で作るので、同じ問題を覚えて答えることはできない。

| 演習 | 京大の大問 | しくみ |
|---|---|---|
| 連鎖計算（32 型） | I・II | 1 つの設定から 4〜7 問を順に解く。前の答えを次に使う。数値は開くたびに変わる。13 の型には、物質収支や平衡定数を文字式で表す設問（4 択。誤答は、2 乗の忘れ・1−α と 1+α の取り違えなど典型的な誤り）が入る。答えは式から計算し、テストで別の経路の検算と突き合わせる |
| 構造決定（数え上げ・特定） | III | 分子式から、鎖式・一置換・二置換ベンゼンの構造異性体をその場で全部作る。性質（級数、酸化、ヨードホルム、銀鏡、脱水、加水分解、オゾン分解、不斉炭素、シス-トランス）は構造から計算する。「特定」は、手がかりを全部満たす異性体が 1 つだけであることを総当たりで確かめてから出す |

追加した演習：

- **構造式を組み立てて答える**：鎖式の化合物の「構造の特定」は、マス目に原子を置いて結合をつなぎ、構造式を自分で作って答える（水素は自動で補う）。組み立てた分子を標準形に直して、答えと同じ分子かどうかを判定する。分子式が違うときは、いまの分子式を返す。ベンゼン環を含むものは選択肢のまま。
- **糖の結合様式**：二糖〜四糖について（グルコースのほか、二糖ではスクロース型・ラクトース型も、四糖では 1→6 の枝分かれも候補に入る）、還元性、α・β を切り分ける酵素、メチル化分析（2,3,4,6-テトラ／2,3,6-トリ／2,3,4-トリ-O-メチルグルコース）から、グリコシド結合の向きと位置を決める。答えが 1 つに決まることを総当たりで確かめてから出す。

それでも足りないところ：

- 構造式の組み立ては、鎖式と、一置換・二置換のベンゼン環（部品として置き、o・m・p を切り替える）まで。三置換の環は選択肢から選ぶ。環式（シクロアルカン、ラクトン）は出題できない。
- 文字式の設問は、画面のキーで式を自分で組み立てて答える（値を何通りか代入して、正しい式と同じ値になるかで判定する。組み立てられないときだけ 4 択に切り替えられる）。
- 論述は 24 題。紙に書いてから模範解答と要点を見て自己採点する形で、文章そのものを機械が採点するわけではない。
- グラフの読み取り・作図、実験装置の図は扱っていない。
- 構造決定は、アミン・アミド・アミノ酸と三置換ベンゼンまで出題できるようになった。環（シクロアルカン、ラクトンなど）はまだ作れない。
- 糖は、環の大きさ（ピラノース・フラノース）や、過ヨウ素酸酸化のような反応までは扱っていない。
- 連鎖計算の文章は短い。京大の長いリード文を読む負荷は再現していない。過去問演習の代わりにはならない。
- 項目の「points」は自分で書き出したもので、教科書の索引との全件照合はしていない。

#### 装置の大きさと出入口

- 蒸留塔・反応器・電解槽・電池は 2×2 マス。出口は 6 か所（正面に 2、右手に 2、左手に 2）で、奥の面の 2 マスが入口の目安。原料はどの面からでも入る。
- 出口には、そこから出る物質の絵柄を描く。設定シートの図で、出口をタップして場所を入れ替えられる。
- 電解槽は左半分が陰極、右半分が陽極。生成物の欄は極ごとに分かれ、1 つの極に 3 つまで書ける。陰極側のものは左手、陽極側のものは右手から出る。以前は「陰極・陽極・ほか」の 3 欄しかなく、硫酸銅(II)水溶液の陽極（O₂ と H⁺）や、アルミナの溶融塩電解の陽極（CO と CO₂）を書けなかった。
- 1 マスだった頃に置いた装置は、古いセーブの中ではそのまま 3 つの出口で動く。新しく置くものはすべて 2×2。
- 生成物は、入れた順に正面・右手・左手と面を分けて出す（以前は 2 つ目も正面に並び、1 本のベルトにまとめてしまいやすかった）。
- その反応で使わない物質が入口に来ると、装置は受け取らず、ベルトはそこで止まる。装置に「！」が出て、設定シートと統計に「使わない ○○ が来ている」と理由を出す。以前は何も表示せずに止まっていた。
- 食塩水の電気分解は、イオン交換膜のほかに、炭素電極・白金電極の水溶液の電気分解としても正解にした。

#### 別解の受け付け

同じ原料から別の生成物ができる反応、同じ目的に別の試薬を使う反応を足した。以前は片方しか正解にならなかった。

- 炭素と酸素：CO₂（完全燃焼）と CO。二酸化炭素とコークス。酸化亜鉛の炭素還元の CO₂ の式。
- アルミナの溶融塩電解：陽極が CO₂ だけ、CO だけ、両方（係数は原子の数が合えばよい）。
- 水素・硫化水素の製法での塩酸、二酸化硫黄の製法での亜硫酸ナトリウム、サリチル酸とフェノールの遊離での塩酸。
- ニトロベンゼンの還元：水素と触媒のほかに、スズと塩酸（アニリン塩酸塩になる）と、その後のアニリンの遊離。
- 水溶液の電気分解：CuSO₄、AgNO₃、CuCl₂、KI。
- 酸化還元の反応式：KMnO₄ と H₂O₂、KMnO₄ とシュウ酸、SO₂ と H₂S、H₂O₂ と KI、ヨウ素とチオ硫酸ナトリウム。生成物が 4 つあるので、出口が 3 つの頃は入れられなかった。

- 工場の効率：納品の速さ（直近 1 分と 5 分平均）、いまの指令の速さと終わるまでの見込み、装置の稼働率、作ったもののうち捨てた割合。10 秒ごとの納品数の推移を棒で出す。

#### 厚みのある絵と、工場らしさ

絵は、このゲームの 2 つのスキンをそのまま立体的にした（ほかのゲームの見た目は写していない）。

- 装置・ベルト・配管・納品所に、手前の側面と地面に落ちる影をつけた。物質はベルトの上に浮かせ、下に影を落とす。納品所はほかより背が高い。
- 稼働中の蒸留塔・反応器は蒸気を上げ、電解槽・電池は火花を散らす。

工場らしさを強める仕組み：

- **電力**：電池が出す e⁻ を電解槽へ流し込むと、流れているあいだ 2 倍の速さで動く（e⁻ 1 個で 2.5 秒、20 秒ぶんまでためられる）。電池と電気分解が 1 本の線でつながる。
- **捨て放題**：廃棄口は煙突で、何でもいくらでも捨てられる。有毒な気体を捨てても罰はない（一度入れた減点は撤廃した）。捨てた数だけ統計に残る。吸収・中和・燃焼の反応 8 つ（塩素や二酸化硫黄を NaOH に吸収、排煙脱硫、アンモニアを硫酸に吸収して硫安、CO の燃焼など）は、製品を作る反応として残してある。
- **操業評価**：指令を終えた時点の、直近 1 分の納品の速さで S（毎分 30 個以上）・A（15）・B（6）・C がつき、研究点が +30・+15・+5 される。仕分けの指令にはつけない。統計に、評価の内訳と有毒ガスの排出数を出す。

#### 複雑な配管を求める仕組みと、組むための道具

- **納品所は全元素を欲しがる機械**。納めた物質の化学式から原子を元素ごとに数え、10・100・1000 個に達するたびにその元素の段階が上がって研究点が入る。全 25 元素を 1 段階まで上げると +300。Cr・Mn・Ba・Sn まで食わせるには、指令の外でも幅広い製造ラインが要る。絵は、中央に回る牙の口、四辺に噛み合う搬入口、外周に元素の印（飲み込むと灯る）。大きくなるにつれて、煙突（4×4）、棘と歯車の環（6×6）、二重の環と脈打つ棘（8×8）が加わる。
- **第20章 コンビナート**（全 10 指令について、最終段の装置を並べて同時に動かし、列車で納品所へ運べば達成できることをテストで確かめた。最初の指令は、入り江の採取機 → 蒸留塔 → 電解槽 → 積む駅 2 つ → 列車 → 降ろす駅 → 納品所と実際に組んで、400 秒以内に達成できることをテストで確かめた）：2〜3 種類の物質を同じ数だけ同時に納める指令 10 個（食塩電解の 3 製品を全部、硝酸と硫酸、鉄・アルミニウム・銅、3 大汎用樹脂など）。副生成物を捨てずに回し、原料を複数の装置へ分ける配管が要る。進み具合は、いちばん遅れている物質で決まる。
- **第21章 量産**：決まった数を納めるのではなく、「毎分 N 個の速さを 20 秒保て」という指令 8 個（N₂ 80、H₂ 50、NH₃ 40、NaOH 24、H₂SO₄ 24、Fe 24、HNO₃ 15、C₂H₅OH 15）。直近 20 秒の納品数から速さを出し、求められた速さを上回っている間だけ時間が貯まり、下回ると倍の速さで減る。1 本のラインでは届かない数にしてあり、採取機・装置・ベルトの本数を計算して並べることになる。全 8 指令について、最終段の装置を必要な台数だけ並べれば達成できることをテストで確かめた。最初の指令は、採取機 2 台 → 蒸留塔 → ベルト → 納品所と画面上で実際に組んで達成できることを確かめた。
- **能力の表示**：反応を設定した装置に「1 台・毎分で作る量と使う量」を出す（強化と電池の加速を含めた値）。量産の指令の間は「この装置が何台分要るか」も出す。採取機とベルトにも毎分の個数を出す。台数を勘ではなく割り算で決めるための表示。
- **出口の規則の変更**：以前は、出口に 1 個でも残っていると次の反応を始めなかった。1 回に 4 個できる反応（空気の分留など）では、ベルトへ 1 個ずつ出している間ずっと止まり、表示した能力の半分ほどしか出なかった（N₂ 毎分 120 のはずが 54〜69）。いまは、どの生成物も残りが 1 回ぶん未満になれば次へ進む。副生成物を放置すると詰まるのは変わらない。直した後、同じ配置で毎分 117。
- **重さの計測と対策**：アドレスに `?perf` を付けると、1 コマの描画と 1 回の計算にかかった時間を記録する。設備 2,600／10,400／26,000 個での計算は 1 回 0.10／0.51／0.76 ms。設備 1 万個を全体表示したときの描画は、地形の絵を毎コマ縮小していたのが重く、約 22 ms かかっていた。縮小ずみの絵を倍率ごとに持つようにして約 1.5 ms になった。遠くから見るときは、ベルトをまとめて 1 回で描き、装置は色つきの四角、物質は点にする。数値はサーバー上のヘッドレス Chromium でのもので、タブレット実機では未計測。
- **範囲**の道具：四角く囲んだ設備を、設定ごとまとめてコピーして貼りつける。まとめて消すこともできる。ラインを丸ごと増設するのに使う。元に戻せる。
- **選別**：分析器に「物質を指定」の設定を足した。指定した物質だけを正面へ通し、ほかは右手へ出す。最初から使える。混ざった流れから副生成物を抜き出して、別々の行き先へ振り分けられる。

#### 長距離輸送・地下・設計図（工場を大きくする道具）

参考にしたのは、工場づくりのゲームで定番になっている機能（設計図の保存と貼りつけ、線路と列車、障害物をくぐるベルト）。見た目は写さず、このゲームの形で作った。

- **分岐と増発**：同じ番線に降ろす駅がいくつもあれば、列車は順番に配る。1 か所だけに送りたいときは線路を自分で敷く。積む駅ごとに 3 編成まで走らせられる。
- **貨物駅と列車**：2×2 の駅を「積む駅」と「降ろす駅」にして、同じ路線番号（1〜8 番線、色つき）にすると結ばれる。線路は自動で引かれ、横に進んでから縦に曲がり、設備や納品所の上を越える。積む駅ごとに線路を少しずらすので、同じ行き先でも重ならない。積む駅ごとに 1 編成が往復し、24 個ずつ運ぶ（駅には 60 個までためられる。降ろす駅が満杯になると「！」が出る）。線路 100 マスで毎分 60 個以上運べることをテストで確かめた（ベルト 1 本は毎分 120 個）。満載になるか、2.5 秒待っても増えなければ発車する。遠いほど往復に時間がかかるので、足りなければ積む駅を増やす。行き先がなくなると、積み荷を持って引き返す。指令を 3 つ終えると使える。列車の速さはベルトの強化で一緒に上がる。
- **線路の網**：道具「線路」で、駅か、敷いてある線路から指でなぞると、線路が地図の上に伸びる。線路は駅のものではなく地図のものなので、どの駅の列車も共有して走る。枝分かれさせると分岐点になり、幹線 1 本に何駅でもつなげる。積む駅は、線路でつながる降ろす駅があればそこだけへ送り（いちばん短い道筋を探す）、1 つもつながっていなければ、これまでどおり自動の仮線路で送る。敷いた線路の上は仮線路の 1.5 倍の速さ。同じ向きに走る列車は前の列車を追い越せず、すぐ先に列車がいれば止まって待つ（先頭の灯りが赤くなる）ので、幹線が混めば運べる量が頭打ちになり、線路をもう 1 本敷いて分ける理由ができる。逆向きの列車とはぶつからない（複線の扱い）。線路は「消す」で消せて、元に戻せる。古いセーブの駅ごとの線路は、読み込むときに地図の線路へ移す。
- **地下ベルト**：同じ向きに 2 つ置くと、あいだの 7 マスまでを地下で運ぶ。上には装置でもベルトでも置ける。2 つ目を置くと、向きは入口に自動でそろう。3 つ以上並べれば中継する。
- **設計図**：「範囲」でコピーしたものを 90° ずつ回せる（2×2 の装置や出口の割り当ても一緒に回る）。置く前に、置ける所は蛍光、ふさがっている所は赤の見本が出る。場所を決めてから「ここに置く」。「保存」すると端末に残り（16 件まで）、どのノートからも呼び出せる。名前は一覧でタップして書き換えられる。
- **ベルトの段階**：ベルトを強化するたびに、中央の流れ線の色が変わり（青 → 緑 → 黄 → 橙 → 紫）、速く流れる。3 段階目からは芯線が入る。
- **道具の棚**：道具が 20 個になったので、「運ぶ・作る・出し入れ・編集」の 4 つの棚に分けた。棚は高さ約 60 px の 1 段（分類 2×2・道具・その道具の切り替え）。説明は道具を選んだ直後だけ出て、数秒で消える。以前は説明・分類・道具の 3 段で約 170 px あり、縦持ちでは上のボタン 8 個まで下へ回って重なっていた。上のボタンは、狭い画面でも上に置いたまま小さくする。

#### 金属イオンの系統分離と貯蔵タンク

第 9 章の「イオンの仕分け」は、1 個ずつ別々の試料を検査で振り分けるものだった。入試で問われるのは、何種類ものイオンが混ざった 1 つの溶液を、試薬の順で分けていく系統分離なので、それを工場として組めるようにした。

- **混合溶液**（`src/content/ions.ts`）：溶液は「入っているイオンの組」を持つ（`ions:Ag.Cu` など）。扱うのは Ag⁺・Pb²⁺・Cu²⁺・Fe³⁺・Al³⁺・Zn²⁺・Ca²⁺・Na⁺ の 8 種。組み合わせが多いので物質の一覧には持たず、求められたときに作る。試薬棚から 6 種類の混合溶液（ア〜カ）が出る。
- **試薬の規則**：希塩酸（第 1 属：AgCl・PbCl₂）、硫化水素・酸性（第 2 属：CuS、残っていれば Ag₂S・PbS）、アンモニア水・過剰（第 3 属：Fe(OH)₃・Al(OH)₃、Ag⁺・Cu²⁺・Zn²⁺ は錯イオンで溶けたまま）、硫化水素・塩基性（第 4 属：ZnS）、炭酸アンモニウム（第 5 属：CaCO₃）、残る Na⁺ は炎色反応（第 6 属）。ほかに、水酸化ナトリウム水溶液・過剰（両性の Al・Zn・Pb は溶ける）、熱水（PbCl₂ だけ溶ける）、クロム酸カリウム（PbCrO₄・Ag₂CrO₄）。
- **順を誤ると混ざる**：1 回の操作で 2 種類以上が沈殿すると「混ざった沈殿」になり、納品に使えない。教科書の手順で分け直せる 2 組（AgCl と PbCl₂、Fe(OH)₃ と Al(OH)₃）だけは、まじりの沈殿として残り、熱水・NaOH で溶かし分けられる。
- **言い切れない組み合わせは使わせない**：Ca²⁺ が残った溶液への NaOH、Cu²⁺・Fe³⁺・Al³⁺・Zn²⁺ が残った溶液へのクロム酸カリウムは、教科書の範囲で結果を 1 つに決められないので、沈殿槽が受け取らず、理由を出す。勝手に結果を作らない。
- **沈殿槽**（2×2）：試薬は 1 台に 1 つ。初めて使う試薬は「沈殿するイオンをすべて選べ」に正解してから使える（2 回まちがえると解説が出る）。ろ液は正面、沈殿は右手から出るので、一列に並べると、ろ液がまっすぐ次の槽へ流れ、沈殿が横へ出ていく。
- **第22章 金属イオンの系統分離**：混合溶液ごとに、各イオンを決まった沈殿の形で納める指令 6 個（2 種 → 3 種 → まじりの沈殿の溶かし分け 2 題 → 6 種 → 8 種すべて）。どの指令も混合溶液から達成できることと、最初の指令を沈殿槽 2 台の工場で通せることをテストで確かめた。CaCO₃・ZnS・AgCl は、鉱山や別の反応からも作れるので、系統分離を通らずに納める抜け道が残っている。
- **貯蔵タンク**（2×2）：物質を 1 種類だけ、200 個までためる。出口を閉じればためるだけになる。別の物質は、空になるまで受け取らない。試薬棚や搬出口から来たぶんは、タンクを通しても指令に数えない。

#### 「混ざったものを順に分ける」を、ほかの単元にも広げる

系統分離と同じ考え方（入試で手順を問われる分離を、混合物を流して装置の順で分ける工場にする）で、2 つ足した。沈殿槽の処理を「1 つ受け取り、正面・右手・左手へ分けて出す装置」として共通化し（`src/content/sep.ts`）、分け方の規則だけを差し替えている。

- **第23章 芳香族化合物の抽出分離**（`src/content/extract.ts`、装置「分液ろうと」）：アニリン・安息香酸・フェノール・ニトロベンゼンのエーテル溶液に、希塩酸（アニリンが塩になって水層へ）、炭酸水素ナトリウム水溶液（安息香酸だけ）、水酸化ナトリウム水溶液（安息香酸とフェノール）を加えて分ける。安息香酸ナトリウムとナトリウムフェノキシドがまじった水層は、CO₂ を通じるとフェノールだけが遊離する。エーテル層に 1 種類だけ残ったら蒸発させて取り出す（2 種類以上残っているうちは受け取らない）。水層に出た塩は、反応器で酸や塩基を加えて元の化合物に戻す（アニリンの遊離、フェノールの遊離、新しく足した安息香酸の遊離）。酸の強さの順（塩酸 ＞ カルボン酸 ＞ 炭酸 ＞ フェノール）だけで全部が決まる。第 18 章の「試料 Y の仕分け」は 1 個ずつの検査だったが、こちらは 1 つの溶液を順に分ける。
- **第24章 アミノ酸の電気泳動**（`src/content/phoresis.ts`、装置「電気泳動槽」）：グルタミン酸（等電点 3.2）・アラニン（6.0）・リシン（9.7）の混合水溶液を、pH を決めて、陰極側・動かない・陽極側の 3 つに分ける。pH を決めるたびに、3 種それぞれがどちらへ動くかを答える（等電点との差が 0.5 以内なら「動かない」）。pH 6 なら 3 種が 1 台で分かれ、pH 1 や 13 では全部が同じ極へ動いて分かれない。
- **確かめたこと**：2 つの章の指令 6 個が、試薬棚の混合物から（塩は反応器で戻して）達成できること。分液ろうと 2 台と反応器 1 台の工場で、アニリンとニトロベンゼンを分けて納められること。電気泳動槽 1 台で 3 種が 3 つのタンクに分かれること。
- **見送ったもの**：気体の精製（洗気びんの順）も同じ形にできるが、できあがる乾いた気体はほかの章の反応で簡単に作れるので、指令にしても分離を通らずに済んでしまう。納品した物の来歴を数える仕組みがないと成り立たないので、今回は入れていない。

#### 反応の見せ方

以前は、反応器はどの反応でも同じ絵で、何の反応をしているかは出口の絵柄でしかわからなかった。

- **物質の実際の色**（`src/content/looks.ts`）：入試で色を問われる物質 52 種だけに、教科書の言い方で色を持たせた（有色の気体は Cl₂ 黄緑色・NO₂ 赤褐色・O₃ 淡青色・F₂ 淡黄色の 4 つ、沈殿、金属イオンの水溶液の色、酸化物・硫化物、単体）。ここに無い物質は色を言わない（「白色」などと勝手に決めない）。図鑑の物質の一覧に、色の見本と言い方が出る。
- **装置の中に反応を描く**：設定ずみの反応器・蒸留塔・電解槽・電池は、その反応で実際に見えるものを描く。水溶液の反応は、液の色が反応の前の色から後の色へ変わり（KMnO₄ の赤紫色が消える、など）、気体は泡になって上がり、色の決まっている溶けない固体は底にたまる。気体どうしの反応は容器いっぱいの気体の色が変わる（2NO + O₂ → 2NO₂ で無色から赤褐色）。固体を熱する反応は粒の山と炎。電解槽は、陰極と陽極に、気体なら泡、金属なら析出を描き、電源の線を電子が陽極から陰極へ流れる。電池は、活物質の色の電極と、負極から正極へ流れる電子、点く豆電球。触媒や条件の短い名前は札で出る。煙も、色のついた気体が生じる反応ではその色になる。
- **水溶液か乾式かの決め方**：塩は固体として持っているが、反応は水溶液で起きるものが多い。条件が加熱で、液体も水溶液の色を持つ物質も入らず、条件に酸・水・溶液の字がないものだけを「固体を熱する反応」として描く。物質ごとの溶解性のデータは持っていないので、沈殿として描くのは、色を決めてある固体だけ。
- **反応式の札**：装置を選ぶと、その下に反応式と条件が出る（可逆反応は ⇄）。うんと近づくと、見えている装置すべてに出る。
- **原子の組み替え**：設定が合った後と、設定ずみの装置を開いたとき、原料の粒がばらけて原子が飛び、生成物に組み替わる動きを見せる。原子は元素ごとに左から右へ 1 個ずつ対応させるので、係数が「原子の数を両辺で合わせるもの」だと目でわかる。全 190 反応のうち 134 は原子を飛ばす。残り 56（混合物や高分子がからんで係数を問わない反応 51、片側の粒が 12 個を超える反応 5）は、粒のまま入れ替わる絵にして、その理由を書く。色についての一言が出るのは 82 反応、中身の色が前後で変わるのは 45 反応。下に「反応の前／後」の見た目（色の決まっている物質だけ）と、気体の発生を言葉で出す。復習の画面には出さない（答えになるため）。

#### 置く手ざわり・研究・信号・2 階（工場づくりのゲームと比べて足りなかった所）

比べた相手の機能は、検索で確かめられた範囲（設計図の書き出しと共有、研究点で開く研究、3 層までの多層、列車と分岐）に基づく。見た目は写していない。

- **置く前の見本**：設備の道具で空いたマスを押し続けると、占めるマス、置けるかどうか、出口（外向きの矢印）と入口（内向きの矢印）が出る。そのまま指を動かして場所を選び、離すと置く。マウスでは乗せるだけで出る。タップですぐ置くのは今までどおり。棚の右端で置く向きを固定できる（自動 → 右 → 下 → 左 → 上）。
- **ベルトの複数本引き**：棚の右端で本数を選ぶと、なぞった線の右手に平行なベルトが並ぶ。角では内側が早く、外側が遅く曲がるので重ならない。引き返すと 1 マスずつ戻る。もとからあるベルトをまっすぐ横切ると立体交差になる。最初は 2 本まで、研究で 3 本・4 本。
- **合流の優先**：2 方向以上から入るベルト（合流点）は、交互に通す。合流点をタップすると、どちらの流れを優先するかを決められる（優先する流れの手前に物があるうちは、ほかは待つ）。主製品を止めたくないときに使う。
- **研究**：「強化」の下に、研究点と計算問題 1 問で開く研究を 10 個、3 段で置いた。段を開くには、それまでに (段 − 1) × 2 個を終える。二者択一が 2 組ある（列車の「急行」か「重連」、工場の「増速運転」か「大口採取」）。切り替えるには、もう一度払う。開くもの：3 本・4 本引き、地下ベルト 7 → 12 マス、信号、2 階、駅の容量と編成数。
- **信号（検知器と弁）**：検知器は、ベルトのように流しながら、「先が詰まって止まっている間」か「決めた物質が通ってから 3 秒間」、1〜8 番の信号を点ける。弁は、同じ番号の信号が来ている間だけ（または来ていない間だけ）通す。配線は引かず、番号で結ぶ。主製品のラインが詰まったときだけ副生成物の捨て口を開ける、といった使い方ができる。
- **2 階**：研究で開く。右上のボタンで階を切り替える。2 階の設備は、同じ x のまま y を 100000 ずらした場所として持つので、ベルトや装置の動きは 1 階と同じ計算で済む。「昇降機」は 2 つで 1 組：置いた側が入口、もう一方の階の同じ場所が出口になり、片方を消すともう片方も消える。採取機と貨物駅は 1 階にしか置けない。2 階を見ているときは 1 階の設備が薄い影で、1 階を見ているときは 2 階の設備がある場所に点線の印が出る。
- **設計図の文字列共有**：設計図の一覧から「書き出す」と、設備の位置・向き・反応の設定を含む文字列になる。ほかの端末や人は「文字列から読み込む」で同じ設計図を使える。壊れた文字列、置けない種類、範囲外の位置は受けつけず、知らない反応は設定だけ外して設備を残す。
- **引いた視点の区画表示**：地図を引くと、近くに固まっている装置を 1 つの区画として点線で囲み、いちばん多くの装置が作っている物質、いまの稼働率での毎分の数、台数の札を出す。
- **状態灯と動き**：設定ずみの装置に、動いている（緑の丸）・原料待ち（橙の三角）・出口の詰まり（赤い四角の点滅）の灯り。採取機は採れている間、土ぼこりやしぶきを飛ばし、走っている列車は煙を残す。
- **魔術スキン**：3 つ目のスキン。羊皮紙（明）と夜の書斎（暗）。ベルトは真鍮の輪で継いだガラス管で、中を青い光の筋が流れる。装置と札は真鍮の二重の縁、動いている装置は四隅の石が灯る。画面部品は明朝体、指令は封蝋つきの紙。部品の作りは文具スキンと同じで、色・縁取り・書体・ベルトと装置の台だけを替えている。
- **音楽**：その場で合成する静かな背景音楽（外部ファイルなし）。4 つの和音をゆっくり回し、動いている装置が多いほど上に乗る音が増える。メニューで切れる。

#### 海水

以前は地図の西がどこまでも海だった。これをやめ、海はほかの資源地と同じ「点在する場所」にした。最初の区画には、西に海が 1 つと、入り江が 4 か所（納品所の東、南西、東の端、北）ある。西へ進んでも陸地が続き、資源地が現れる。遠くの区画にも、ほかの資源地の 3 倍の割合で現れる。

#### 運転条件の計算

塩化銀の沈殿、窒素のボンベ充填、ヨウ化水素の分解は、反応の設定が合ったあとに、その装置の条件（沈殿が始まる濃度、ボンベの圧力、速度の変化）を計算して入力しないと動かない。

#### 仕分けの課題の仕組み

- 「試薬棚」で試料の組を選ぶと、絵柄では区別できない数種類が順に流れてくる。
- 「分析器」は検査を 1 つ行い、陽性を正面、陰性を右手へ分ける。直列につなげば条件を重ねられる。
- 目的の物質だけを納品する。同じ試料の別の物質を納めると 2 個減点。
- 各検査で「わかること」は折りたたんであり、まず自分で思い出す前提。
- テストで、仕分けの指令すべてについて、目的の物質が検査の組み合わせで他と区別できることを確認している。

#### 可逆反応と緩衝液

- ハーバー・ボッシュ法、接触法、メタノール合成、水蒸気改質、石灰石の熱分解は、触媒に加えて「平衡を生成物側へ動かす温度と圧力」も答えないと動かない。
- 緩衝液は、酢酸と酢酸ナトリウムの混合比を係数で指定する。Ka から比を計算する。

#### 専用パイプについての判断

液体・気体を専用のパイプで運ぶ案は、**別の道具にはしなかった**。理由：

1. 工業プロセスでは反応条件下の状態と常温の状態が食い違う物質が多く（SO₃、アセトアルデヒド、水溶液として扱う NaOH など）、「正しい管」を一意に決められない。誤った暗記を誘う。
2. 道具の持ち替えが増える。タブレットでの手数は、以前に指摘された弱点そのもの。
3. 入試で状態が問われるのは、ハロゲンの単体や捕集法など限られた場面で、そこは第 8 章と復習の知識問題で直接扱える。

代わりに、**線の見た目が、流れている物質の常温での状態で自動的に変わる**ようにした（固体＝幅広のコンベヤ、液体＝管、気体＝細い管）。操作は増えず、状態は常に目に入る。物質の台の形（丸・しずく・角丸）と対応している。

#### 便利機能

- ベルトを引いて別のベルトをまっすぐ横切ると、交点が自動で立体交差になる。直角に乗って止めれば合流。立体交差は最初から使える。
- 早送り（×1 → ×2 → ×4 → 停止）。
- 複製：設定済みの装置を選んで「複」を押すと、同じ設定で続けて置ける。
- 詰まりの表示：出口がふさがった装置には「!」が付き、設定画面に「何が足りないか／どの出口が詰まっているか」が出る。
- 試薬棚：実験室の試薬 20 種を取り出せる（そのまま納品しても指令には数えない）。

#### 弱いところ

- 難易度と所要時間は、人が通しで遊んで調整していない。指令ごとの所要時間は記録しているので（記録画面）、遊んだあとに数字で見直せる。
- 工場の中の仕分けの指令は、用意した 23 組の試料から区別できる物質を拾う方式。新しい分子を作り出すのは、工場の外の「構造決定」の演習だけ。
- 解説文・検査の表・問題の答えは、一部を検索で裏取りしただけ（乾燥剤、両性と錯イオン、ヨードホルム反応、鉛蓄電池）。教科書との全件照合はしていない。

#### 仕組みの追加（これまで）

- **立体交差の直後の曲がり**：立体交差を抜けた先のベルトが曲がっていると流れが途切れる不具合を直した（立体交差の先は、入ってきた向きのまま受け取る）。

- **元素ごとの固有の形**：物質の絵柄は元素の形の組み合わせ。色は炎色反応や単体・イオンの色に合わせた。
- **大気はどこでも採れる**。
- **強化**：研究点と計算問題で、採取・ベルト・装置が 5 段階まで速くなる。
- **装置**：電池、分配器、立体交差、搬出口、試薬棚、分析器、捕集器。
- **あふれ**：装置に入れすぎた原料は捨てられ、1 本のベルトに混ぜても詰まらない。
- **図鑑**、**タイトル画面とセーブ 3 枠**（端末ごと。文字列で書き出し・読み込み）、**音**。

### 操作と見た目の方針（タブレット）

- システムキーボードを出さない。化学式は専用キー（元素を多めに並べ、答えの手がかりにしない）、係数は −／＋、条件は選択肢のタップ。
- 道具の持ち替えを減らす。置いたものをタップすると、その場に「設定・回す・消す」が出る。装置やベルトから指を引くとベルトが伸びる。
- 置く向きは、流れ込みがあればその向き、なければ納品所の方角に自動で決める。
- 最初は指で押せる大きさで始め、「全体」で地図全体へ切り替える。画面外の資源地は縁の道しるべで示す。指を離すと地図は少し滑る。
- 見た目は有機的に：地形はマス目ではなくにじんだ塊、資源地は不定形、ベルトは角で曲がる一続きの管、装置と UI は丸い形。

## 6. リスク

1. **開発が勉強時間を食う**。最大のリスク。実装は任せて、本人の作業は「遊んで誤答ログを残す＝勉強」に限定する。仕様に凝り始めたら危険信号。
2. **受験までの残り期間**。高3で今（11月）から始めるなら、このゲームは間に合わず有害。過去問と共テ演習に全振りすべき。高1・高2なら M2 までを早期に作れば元が取れる。→ 学年で計画の規模を変える。
3. **有機の構造式表示と反応規則**が重い。M2 冒頭で試作し、無理なら扱う化合物を教科書掲載の範囲に限定した表引き方式へ落とす。
4. **内容の誤り**。§2 の自動テストと出典必須で抑えるが、最終確認は教科書と照合する。
