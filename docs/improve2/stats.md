## 補足

- **前からあった不具合を直した**：統計の「納品数の推移」の棒が、学習のグラフの CSS（`.bars .bar` の grid）に負けて、高さが 0 になり見えていなかった。`.chart .bars .bar` で直した。
- **新しい World の項目**（どれも読み込むときに形を確かめ、合わないものは捨てる）：`hour`（1 分ごとの流れ。セーブでは `hist` に [分, 納品, 指令, 廃棄口, あふれ, 作った] の数の並びで最大 60 行）、`ach`（実績の id → 得た時刻）、`eta`（'章:番号' → 見込みの秒数）。保存しないもの：区切りごとの物質ごとの数（`Bucket.sub`）と在庫（`Bucket.stock`）、ベルトごとの通った数（WeakMap）。
- **画面効果のきっかけ**（`World.fx`）に `train`（降ろした数 n つき）と `goal` を足した。render.ts の spawn は、この 2 つを mapfx.ts に渡して、ふつうの粒子は出さない。
- **この端末の表示の好み**（期間・たたんだ見出し・色分け）は `localStorage` の `chemyth-v2-stats` に置く。読めなくても既定のまま動く。
- 実績・見込みの記録は、本編の工場を動かしている間だけ（半秒に 1 回）。課題の工場では数えない。
- 大きな工場（ベルト 8600・装置 200）での 1 コマの描画の中央値：重ね表示と色分けありで、引いた視点 2〜4 ms、近い視点 5 ms（ヘッドレスの Chromium、標準の画質）。統計を開くのは 40 ms ほど。
