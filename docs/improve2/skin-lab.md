# 4 つ目のスキン「研究所」（2026-11-12）

近未来の化学研究所。文具・工業・魔術に続く 4 つ目のスキンとして、スキンの切り替え（タイトルとメニューの「見た目」）に「研究所」を足した。
明暗は 2 つ。

- **白の研究棟**（ライト）：白い陶板の床、銀の縁とガラスの装置、青緑の立体映像。照明は天井いっぱいから回り込むので、影はやわらかく短い。
- **深夜のラボ**（ダーク）：黒く磨いた床に、青緑と赤紫の灯が映る。光の帯と立体映像。

確かめ方の印：**型**＝`tsc --noEmit`、**単体**＝`vitest run`（724 件）、**目視**＝ヘッドレスの Chromium（Playwright、WebGL は SwiftShader）で撮った画面写真を見て確かめた、**計測**＝`?perf` の描画時間。
実機のタブレットでは、まだ確かめていない。

重い絵（床の区画、装置の殻と影）は一度描いてためておくので、毎コマの重さは、ほかのスキンと変わらない。絵の本体は `src/ui/skinLab.ts` にまとめ、`render.ts` からは短い呼び出しだけで使う。

## 画質ごと

| 画質 | 内容 | 確かめ方 |
|---|---|---|
| 標準 | 上のとおり（Canvas 2D だけ）。夜は、稼働中の装置と納品所が暗がりに光をこぼす | 目視 |
| 高 | 澄んだ強めの発光、粒子はごく少なく、色のにじみはほぼなし。ベルト・状態の帯・床の光の帯が光る。納品所の字の窓は、効果の層（緑）で色を守るので、光に埋もれない | 目視 |
| 最高 | **磨いた床の映り込み**：床の点から奥へ高さの層をたどり、背の高い物の足もとを見つけたら、足もとを境に折り返した所の絵を、ぼかして薄く重ねる。背の高い物ほど長く映る。灯（発光のぼかし）は奥から縦に集めて、床に落ちる光の筋にする。水と、装置・ベルトの上には映さない。ほかのスキンは `reflect: 0` なので計算しない。色調は、昼は青みの白、夜は暗がりを青緑・明るい所を赤紫に寄せる | 目視 |
| 立体表示 | 箱の側面は、つやのあるパネル（マスごとの継ぎ目、斜めに走る照り、足もとの黒い帯）と、上の縁に沿って光る帯（夜は高画質で光る） | 目視 |

ほかのスキンが変わっていないことは、もとの版（5f8089f）と同じ時刻・同じ工場で「文具・ノート・最高」を撮り比べて確かめた（画面全体の平均の明るさは 208.8 と 209.0。違う画素は 2% ほどで、動いている荷・列車・水面）。

## 画面部品（CSS）

`style.css` の最後に、研究所スキンの塊を 1 つ足した。部品はすりガラスの板（うしろをぼかし、細く光る縁と、やわらかい影、角は丸く）。
ぼかしは大きな板（指令・道具の棚・窓・お知らせ・表紙など）だけにかけ、上の小さなボタンにはかけない（毎コマの合成が重くならないように）。
書体は、すでに読み込んでいるものだけを使う（見出しは Zen Kaku Gothic New の太字、数字は Chakra Petch）。表紙の見出しは「化学研究所 ／ 受験化学」、その下に明暗の名前を出す。セーブ枠は「第 1 研究室」。

| 所 | 確かめ方 |
|---|---|
| タイトル（表紙・セーブ枠・スキンと明暗の切り替え）、メニューの窓、図鑑の窓、指令、道具の棚、上のボタン、お知らせ、小地図 | 目視（明暗とも） |
| 装置の設定の窓（説明・出入口の図・原料の札・係数の増減・化学式の欄）、強化の窓（研究点・強化のボタン・段の目盛り・研究のカード）、選んだものの操作の帯 | 目視（明暗とも） |
| 化学式の鍵盤、復習・問題の窓、統計の札、閉店のシャッター | 未（規則は書いたが、画面では見ていない） |

## 重さ

同じ大きな工場（`big-save.json`）、同じ視野、1180×820、端末の画素比 2。SwiftShader（CPU で描く WebGL）で、ほかの作業と CPU を分け合っているので、比で見る。描画の中央値（ミリ秒）。

| 画質 | 闇の炉（工業） | 深夜のラボ（研究所） |
|---|---|---|
| 標準（1 回目） | 4.0 | 3.0 |
| 標準（2 回目） | 4.0 | 3.0 |
| 最高（2 回目） | 68 | 54 |

WebGL の段は 1 回に数コマしか測れず、ばらつきが大きい。研究所の映り込みで、目に見えて重くなる様子はなかった。
