# グラフィックの刷新：第 1 ラウンドの現状

設計は [SPEC2.md](SPEC2.md)（規範。批評 3 本と 2 回目の点検を通した版）。方針は 3 つ：

1. **ひとつの光**：光源は見た目ごとに 1 つの「部屋の光」。地図は北が上のまま、光はいつも画面の上半分から来る。
2. **物質の色は事実**：物質は白い光の下での色（教科書の色）で描き、時刻・光・画質の設定では変えない。色・燃焼・温度・気体・分析の試薬・保存法・説明文は、出典つきのデータと検査にする。
3. **地図の上の情報は光で変えない**：文字・札・印は光の計算の外に置く。

## まだのもの（SPEC2 §5 の第 1 ラウンドの残り）

- **S0**：`render.ts` を `rctx.ts`・`ground.ts`・`ambient.ts`・`machines.ts`・`matter.ts`・`plumes.ts`・`keep.ts` に分け、つなぎ目 S1〜S18 を、画素を変えずに入れる。決まった撮影（`?det`）と `__fx` の測定の道具。
- **L の残り**：ひとつの光の状態（LightState）、HDR の光のにじみ、物質の色を画素単位でそのまま通す keep の印、どの画質でも同じ夜の場、光のふりをする演出の撤去（L0）、立体表示の箱の陰影。
- **H の配線**：形の層を GPU で描き、いまの高さの層（Canvas2D）と FS_SHADE のぼかしを置きかえる（最高の平面表示だけ）。
- **M**：装置の中の本物の実験（液の濃淡、沈殿・白濁・層、2:1 の泡、青いバーナー、熱で光る融解塩、分析器の試験管と銀鏡・チンダル現象、捕集）、廃棄口の気体の重い・軽い・白煙・NO→NO₂。
- **§7 の関門**：見た目 8 × 画質 × 時刻の撮影の行列、標準の重さの台帳、性能の測定。

第 2 ラウンド（大域照明・水の場・気体の場）と第 3 ラウンド（8 つの見た目の美術）は SPEC2 §8・§9。
