# Chemyth

大学受験化学（共通テスト〜京大二次）を、工場自動化パズルとして学ぶタブレット向けブラウザゲーム。
資源地から原料を採り、装置に反応を自分で設定し、指定された物質を納品する。
空気と水から始まり、無機工業、製錬、電池、有機、高分子、気体の捕集、イオンの分離、構造決定、結晶・溶液・コロイドまで 24 章・275 指令、反応 192 種。
工場の外に、計算問題 116 問、知識問題 140 問、間隔を空けた復習、京大形式のリード文課題 8 題。
京大の大問の形に合わせた演習：連鎖計算（32 型。文字式は自分で組み立てて答える）、有機の構造決定（分子式から異性体を全部作り出し、数え上げと特定。構造式は自分で組み立てる）、ペプチドの配列決定、糖の結合様式、論述（24 題、要点で自己採点）。
納品所は全元素を欲しがる機械で、飲み込んだ元素が増えるほど報酬が出る。終盤は、複数の製品を同時に納めるコンビナートと、「毎分 N 個の速さを保て」という量産の指令。装置には 1 台あたりの毎分の能力が出るので、必要な台数を計算して並べる。廃棄口には何でも捨ててよい。
遠くの資源地からは貨物駅の列車で運び、装置の下は地下ベルトでくぐる。線路は地図に敷く共有の網で、枝分かれさせて何駅でもつなげる（混むと列車が待つ）。設計図は回して保存でき、文字列にして人に渡せる。
置く前に見本（占めるマス・出口・入口）が出る。ベルトは 2〜4 本まとめて引け、合流点には優先を決められる。研究（二者択一あり）で、信号（検知器と弁）や 2 階（昇降機でつなぐ）が開く。地図を引くと、区画ごとに何を毎分いくつ作っているかが出る。背景音楽はその場で合成する。
装置の中には、その反応で実際に見えるもの（液の色の変化、気体の泡、沈殿、炎、電極での析出、電子の流れ）を描く。設定が合うと、原料の原子が飛んで生成物に組み替わる動きが出る。入試で問われる色（NO₂ 赤褐色、Cl₂ 黄緑色、CuSO₄ 水溶液 青色、AgCl 白色沈殿 など）は `src/content/looks.ts` にある。
範囲コピーで製造ラインを丸ごと増設でき、分析器は物質を指定した選別にも使える。電池の e⁻ で電解槽を加速でき、指令ごとに納品の速さで操業評価（S〜C）がつく。
「統計」で、納品の速さ・装置ごとの稼働率と止まっている理由・捨てた割合・学習の進みを見られる。稼働率は地図に重ねて表示できる。
学習指導要領の「化学基礎」14 項目・「化学」20 項目との対応は、ゲーム内の「メニュー → 範囲表」と `src/content/syllabus.ts` にある。
金属イオンの系統分離は、混合溶液を「沈殿槽」に通し、試薬の順（希塩酸 → 硫化水素 → アンモニア水 → …）を自分で決めて 1 種類ずつ沈殿させる。順を誤ると沈殿が混ざる。同じ形で、芳香族化合物の抽出分離（「分液ろうと」で、どの水溶液で何が水層へ移るかを決める）と、アミノ酸の電気泳動（「電気泳動槽」で pH を決めて 3 方向に分ける）もある。作ったものは「貯蔵タンク」にためておける。
「課題」は、本編とは別の小さな工場を渡す：1 か所だけ誤った工場を直す、数の決まった原料からできる数を先に計算する、封印された装置の反応を数の比から当てる。「模試」は、自分の工場で動いている反応がそのまま京大形式の問題文になる。
章を終えると炎色反応の色で花火が上がり、復習で覚えている反応ほど装置が銅 → 銀 → 金になる。達成した瞬間の工場はアルバムに残り、タイトルの本棚と地図の灯りが増えていく。
見た目は「文具」（方眼ノート／黒板）、「工業」（光の炉／闇の炉）、「魔術」（羊皮紙／夜の書斎。ガラス管と真鍮）の 3 スキン × 明暗。
WebGL2 が使える端末では、地図の絵に発光・照明・熱のゆらぎ・水面のきらめきを重ねる（メニュー →「画質」で切り替え。重い端末では自動で標準の画質に戻る）。
タイトルの「アカウント」で登録・ログインすると、セーブが端末どうしで自動でそろう（メールは使わない。アカウント名と合言葉だけ。データベース側は `supabase/migrations/0002_accounts.sql`）。
メニュー →「立体表示」をオンにすると、傾いた視点から見た立体の工場になる（装置は箱になり、影が落ち、2 階は上に浮く。初めはオフ）。

- 計画：[docs/PLAN.md](docs/PLAN.md)

```
npm install
npm test         # 原子数の収支、全指令の到達可能性、採点、工場の動作
npm run build    # dist/index.html（単体で開ける1ファイル）
```

## 公開（GitHub Pages）

`.github/workflows/pages.yml` が、push のたびにテスト・ビルド・公開を行う。
最初に一度だけ、リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にする。

## ランキング

Supabase のプロジェクト「chemyth」につないである（`src/config.ts` の `RANKING`）。
表の定義は `supabase/migrations/0001_ranking.sql`。表には直接さわらせず、登録用と取得用の関数だけを公開している。
別のプロジェクトにつなぎ替えるときは、その SQL を実行して URL と publishable キーを書き換える。
接続できないとき（共有用の断片ページなど）は、端末内のノート同士の順位だけが出る。
